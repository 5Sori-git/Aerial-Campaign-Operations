# 테스트 체크리스트 (미검증 기능)

원격 작업 중에 만들어 컴파일만 확인한 기능들. 테스트하면서 `[ ]` → `[x]`로 바꾸고, 문제는 항목 아래에 적는다.
마지막 컴파일 확인: 2026-10-27 (C# + U# 125개 스크립트, 오류 없음).

---

## 0. 테스트 전 셋업 (순서대로)

> 도구는 **ACO → Tools...** 한 창에 모여 있다(설명 포함). 먼저 그 안의 **셋업 검사(ACO → Setup Check...)** 를 열어 오류/경고를 [고치기]로 정리하면 아래 대부분이 채워진다. 위치(갑판·브리핑실·격납고 지점, 보관 장소, 안전지대 콜라이더)는 직접 옮겨야 한다.

- [ ] Ctrl+R 컴파일 확인 (Console에 빨간 오류 없음)
- [ ] `ACO → Create Prefabs...`에서 다시 만들기
  - [ ] NPC 전투기 (플레어 파티클이 새로 들어감)
  - [ ] 폭탄 / 로켓 (ACO_Ordnance)
  - [ ] 작전 콘솔 (UI 버튼 방식)
  - [ ] 격납고 (특수무장 해금 + 강화 상점 탭) — 판이 2.8 × 1.5m로 커졌으니 씬에서 위치 다시 잡기
- [ ] 플레이어 기체 선택 후 셋업 메뉴 (`ACO → Player Missile → ...`)
  - [ ] Replace DFUNC_AAM on Selected Vehicles
  - [ ] Add Special Weapon Slot on Selected Vehicles (오른쪽 다이얼 Element 2, 키 3)
  - [ ] Add ACO Bomb + Rockets to Special Slot on Selected Vehicles
  - [ ] Add Upgrade Extension to Selected Vehicles (Replace 메뉴를 썼으면 이미 들어가 있음)
- [ ] `ACO → Create Player Progress` (씬에 하나만)
- [ ] 무장 모듈마다 인스펙터 `UpgradeFamily` 드롭다운 확인
  - 일반 미사일 = Missile, 4AAM = SpecialAAM, UGB/RKT = SpecialBomb
  - 대지미사일(만들면) = SpecialAGM + `MissileSplash` 켜기 + `TargetLayers` 지상(30)만
- [ ] `ACO → Bake NPC References` → Console 경고 확인(강화 확장 없는 기체, AGM인데 MissileSplash 꺼짐 등)
- [ ] 씬 저장

## 1. NPC 전투기 동기화 / 오너십

- [ ] 선회 중 NPC가 툭툭 튀지 않는다 (클라이언트 2개 이상)
- [ ] 교전 중인 플레이어에게 오너십이 넘어간다 (2초 유지 후, 넘어간 뒤 5초 쿨다운)
- [ ] 오너가 바뀌는 순간 기체가 순간이동하지 않는다
- [ ] 늦게 들어온 클라이언트에서도 NPC 위치가 맞다
- [ ] 등급별 외형: 신병/베테랑/에이스 전투기가 각자 넣은 모델로 보인다(모든 클라이언트), 격추 후 부활해도 다른 등급 모델이 같이 켜지지 않는다

## 2. 플레이어 미사일 (ACO_DFUNC_Missile, DFUNC_AAM 대체)

- [ ] 대공(29)/대지(30) 표적 레이어대로 락온된다, 자기 기체는 락온 안 됨
- [ ] 슬롯 장전: 쏜 슬롯만 SlotReloadTime 뒤 다시 찬다, 잔탄 0이면 빈 슬롯 유지
- [ ] HUD 세로 슬롯 막대가 장전 진행을 보여 준다
- [ ] 명중 시 "쾅" 소리 + 기수 튐 (ImpactPush/ImpactSpin)
- [ ] 후연: 폭발 후에도 이미 뿌린 연기가 남았다 사라진다 (ExplosionDuration ≥ 파티클 수명)
- [ ] 다른 클라이언트에서도 같은 궤적으로 보인다

## 3. 락온 HUD (표적 테두리)

- [ ] 락온 시도 중 테두리가 일정 속도로 계속 깜빡인다
- [ ] 이름표가 뜬다
- [ ] 마름모가 무작위 방향에서 다가와 락온 완료 시 테두리에 겹친다
- [ ] 특수무장(4AAM 등)을 고르면 마름모 대신 십자(+)가 다가오고, 일반 미사일로 바꾸면 다시 마름모
- [ ] 락온 완료 시 빨간색
- [ ] 다중 락온(4AAM): 표적마다 따로 연출, 정보 라벨도 모든 락온 표적에

## 4. 특수무장 슬롯 / 격납고

- [ ] 격납고에서 고른 무장이 조종석에 앉을 때 장착된다 (플레이어별)
- [ ] 다른 클라이언트에도 같은 무장 외형이 보인다, 늦게 들어온 사람도
- [ ] 4AAM: 락온한 표적당 1발 (2개 락온 → 2발, 4개 → 4발 일제)
- [ ] 4AAM 장전 방식이 일반 AAM과 같다
- [ ] UI 버튼(레이저)으로 작전 콘솔·격납고가 눌린다
- [ ] 데스크톱: 원래 AAM 키로 ACO 미사일이, 숫자 3 키로 특수무장 슬롯이 선택된다(Bake가 키보드 단축키를 옮김)

## 5. 폭탄 / 로켓 (ACO_Ordnance) + CCIP

- [ ] 폭탄이 기체 속도를 이어받아 날다가 떨어진다
- [ ] 다른 클라이언트에서도 비슷하게 보인다 (SAV 방식, 약간 어긋나도 OK)
- [ ] 범위 피해: 중심 Damage → 가장자리 MinSplashFraction, 아군 호위 대상은 피해 없음
- [ ] 로켓: 트리거를 누르고 있으면 연사
- [ ] CCIP 레티클이 실제 낙하 지점과 맞는다 — 고도 1000m 이상에서도(고정 간격 궤적), 폭탄·로켓이 90fps에서 매끄럽게 움직인다
- [ ] 폭탄 범위 피해: 무장(ACO_DFUNC_Missile)의 SplashRadius 안 유닛이 전부 피해를 받는다(DebugHitLog로 반경·피해 유닛 확인, 큰 반경에서도 빠지는 유닛 없음)

## 6. 플레어 (에이스컴뱃식 100% 회피)

- [ ] NPC: 미사일마다 한 번 확률 판정 (루키 10%, 베테랑 50%, 에이스 90%)
- [ ] NPC가 플레어를 뿌리면 플레이어 미사일이 플레어 쪽으로 끌려가 빗나간다 (피해 없음)
- [ ] 플레이어가 SAV 플레어를 켜면 NPC/SAM 미사일이 똑같이 빗나간다 (레이더 유도 미사일도 — `AnyCountermeasure` 기본 켬)
- [ ] 플레어 파티클·소리가 모든 클라이언트에 보인다
- [ ] (플레어 장치) NPC 전투기 프리팹을 다시 만들면 루트에 ACO_FlareDispenser, AI의 Flares에 연결 — 셋업 검사 경고 없음(예전 프리팹이면 [고치기])
- [ ] 등급별 플레어 확률·반응 거리가 그대로: 신병은 거의 안 뿌리고 늦게, 에이스는 거의 항상 일찍, 슈퍼에이스는 항상(12번)
- [ ] (장치의) FlareUseEmitter를 켜면 파티클 시스템 Bursts 간격대로 플레어가 뿌려지고 FlareEmitDuration 뒤 멈춘다, 연달아 뿌리면 끄는 시각만 늦춰진다

## 7. 재화 / 강화 / 해금

### 보상
- [ ] 미션 성공, 격추 0회 → (팀 점수 × 50% + 개인 점수) 100%
- [ ] 격추 1회 → 55%
- [ ] 격추 2회 이상 → 10%
- [ ] 미션 실패 → 10%
- [ ] 출격(조종석 탑승) 안 함 → 0 (NO SORTIE)
- [ ] 추락도 격추로 센다
- [ ] 안전지대(항모 갑판 콜라이더) 안에서 내리면 페널티 없음, 밖(공중·바다·다른 섬)에서 내리면 격추 1회(폭발로 내려진 경우는 1회만)
- [ ] 미션이 끝나 브리핑실로 강제 귀환할 때 내리는 건 격추로 안 센다
- [ ] 작전판 디브리핑 머리줄과 격납고에 REWARD 줄이 뜬다
- [ ] 늦게 들어와서 출격해도 보상을 받는다

### 저장 (PlayerData)
- [ ] 월드를 나갔다 다시 들어와도 크레딧·강화 단계·해금·마지막 고른 무장이 남는다
- [ ] 들어오자마자(불러오기 전) 상점에 LOADING이 뜨고 구매가 막힌다

### 강화 (다음 탑승부터 적용)
- [ ] AIRFRAME: 체력(HUD 체력 비율), 기동, 추력이 체감된다, 연료 효율 강화 후 같은 비행에서 연료가 덜 줄어든다(애프터버너 포함), 안정성 강화 후 저속에서 덜 처지고 실속이 늦다 — 플랩을 내렸다 올려도 내린 뒤 원래 양력으로 돌아온다
- [ ] MISSILE / SP.AAM: 데미지·잔탄·선회·락온속도·락온거리·락온범위·재장전 속도
- [ ] SP.AGM / SP.BOMB: 데미지·잔탄·폭발범위·재장전 속도
- [ ] 재장전 속도: 5단계에서 슬롯 장전 막대가 눈에 띄게 빨리 찬다(약 1.4배), 내리면 원래 속도
- [ ] (먼저) Bake 후 진행도 인스펙터의 강화 배열이 27개로 늘고 기존 이름·가격이 제자리에 남는다, 격납고 프리팹을 다시 만들면 MISSILE·SP.AAM 탭이 7줄, 예전에 산 강화 단계가 그대로
- [ ] 내리면 원래 값으로 돌아간다 (다른 사람이 같은 기체를 탔을 때 내 강화가 남지 않음)
- [ ] 잔탄 강화 악용 방지: 다 쏘고 내렸다 다시 타도 탄이 공짜로 차지 않는다
- [ ] 상점 탭 전환, 줄 색(살 수 있음 녹색 / 모자람 회색 / 최대 밝은 녹색)

### 특수무장 해금
- [ ] 처음엔 4AAM 포함 전부 잠김 → 특수무장 없이 출격 (슬롯 선택해도 아무 일 없음)
- [ ] 잠긴 무장을 누르면 설명·가격, BUY로 사면 바로 장착
- [ ] 크레딧이 모자라면 NOT ENOUGH CREDITS
- [ ] 격납고 PreviewVisuals: 무장 버튼을 누르면(잠긴 무장 포함) 그 무장의 미리보기 오브젝트만 켜진다, 다른 사람 화면엔 영향 없음

### 대지미사일 (만든 뒤)
- [ ] MissileSplash 켠 유도 미사일이 터진 자리에 범위 피해 (직격 표적은 중복 피해 없음)
- [ ] 지면에 빗맞아도 범위 피해가 들어간다

## 7-1. 게임 진행 (명단 / 준비 / 출격)

셋업: `ACO → Create Game Flow` → DeckPoint_1~4를 항모 갑판 위로, 참가자 기체 4대의 원래 위치를 안 보이는 보관 장소로(떨어지지 않게 바닥 콜라이더), 로비·격납고·항모에 `ACO_Teleporter` 버튼 배치, 작전 콘솔·격납고 프리팹 다시 만들기, Bake.

- [ ] 로비 콘솔 JOIN → 명단에 이름, LEAVE → 빠짐, 5번째 사람은 못 들어감
- [ ] 페이즈 버튼이 미션을 바로 시작하지 않고 페이즈 수만 바꾼다(명단 제목에 표시)
- [ ] 격납고 READY/CANCEL READY, 명단 전원 READY → 미션 시작 + 전원 동시에 갑판의 자기 칸 기체에 탑승
- [ ] 기체가 갑판 위치에 정확히 놓이고 튀거나 떨어지지 않는다(다른 클라이언트에서도)
- [ ] 격추 → 기체가 보관 장소로 리스폰 → 격납고 LAUNCH(RESPAWNING 표시 후)로 재탑승
- [ ] 미션 도중 JOIN(난입) → 격납고 LAUNCH로 출격, 보상도 받음
- [ ] 참가자 기체의 파일럿 좌석은 눌러도 반응이 없다(상호작용 표시 없음) — LAUNCH로만 탄다
- [ ] 착륙 후 내리면 30초 뒤 기체가 보관 장소로 돌아간다
- [ ] 미션이 끝나면 명단·준비가 비워진다(비행 중인 사람은 그대로 비행)
- [ ] 명단에 있던 사람이 나가면 칸이 비워진다, 오너가 나가도 명단이 유지된다
- [ ] `ACO_Teleporter`로 로비 ↔ 격납고 ↔ 항모 이동 — 화면이 어두워졌다 밝아진다(VR·데스크톱 둘 다, 마커/HUD보다 위에 덮임)
- [ ] LAUNCH 때도 암전 → 어두운 동안 탑승 → 밝아짐(오너 대기가 길면 어두운 채 기다림)
- [ ] 미션 완료/실패 8초 뒤 모든 플레이어(관전자 포함, 비행 중인 사람은 내린 뒤)가 브리핑실로
- [ ] 미션 중 명단 밖 사람의 격납고 버튼이 SPECTATE로 바뀌고, 누르면 갑판 관전 위치로
- [ ] 로비 REROLL TERRAIN: 명단에 있는 사람만, 미션 전에만, 30초 간격 — 모든 클라이언트에서 같은 새 지형, 명단 제목에 지형 이름(GENERATING → 이름)
- [ ] 리롤하면 READY가 풀린다
- [ ] 미션 시작 때 지형이 다시 바뀌지 않는다(리롤한 지형 그대로), 리롤 직후 바로 시작해도 유닛이 지형 위에 제대로 놓인다
- [ ] 미션이 끝나고 모두 내린 뒤에야 새 지형이 생긴다(비행 중엔 안 바뀜)

## 7-0a. 격납고 아이콘
- [ ] 격납고 프리팹을 다시 만들면 강화 줄·탭·특수무장 버튼·크레딧에 아이콘이 붙는다(Textures/Icons의 PNG가 Sprite로 바뀐다)
- [ ] 탭을 바꾸면 강화 줄 아이콘이 그 분류의 능력치 그림으로 바뀐다
- [ ] 잠긴 특수무장 버튼 구석에 자물쇠, 사면 사라진다
- [ ] VR에서 멀리서 봐도 아이콘이 깨지지 않는다(밉맵), 아이콘이 버튼 누르기를 막지 않는다

## 7-1a. 대기실 통합 / 전원 준비 10초 카운트다운
- [ ] (씬) 작전 콘솔·격납고 패널·작전 테이블을 한 방에 두고 HangarPoint를 비운다(지우거나 None), 방 사이 텔레포터 제거
- [ ] 격추·안전지대 밖 하차 시 5초 뒤 대기실(BriefingPoint)로 돌아온다
- [ ] 명단 전원 READY → "ALL READY - LAUNCH IN 10s" 카운트다운 뒤 일제 출격
- [ ] 카운트다운 중 REROLL·페이즈 버튼이 막히고 안내 메시지가 뜬다
- [ ] 카운트다운 중 누가 CANCEL READY 하거나 새로 JOIN하면 카운트다운이 취소된다(새 참가자는 60초 준비 카운트다운으로)
- [ ] 절반 이상 READY → 60초 뒤 READY 안 한 사람이 빠지고 10초 카운트다운으로 이어진다
- [ ] 카운트다운 중 오너가 나가도 새 오너가 이어서 시작한다

## 7-1b. 여러 명 플레이 예외 처리

- [ ] 월드를 연 뒤 30초 동안 리롤 버튼이 REROLL AVAILABLE IN Ns로 막힌다

## 7-63. 비행 HUD (SAV HUD 대체)

- [ ] (비행 HUD 프리팹을 다시 만든 뒤) 글자가 예전의 1.5배, HUD 전체는 설정 ×1.0에서 예전 ×0.5 크기. 피치 래더 간격이 10°마다 좁게(약 ±20°가 보인다) 놓이고 기수를 들면 천천히 움직인다. 글자끼리 겹치지 않는다(속도·고도 상자, 잔탄 세 칸, HP)
- [ ] HUD 설정 FLIGHT HUD: SHOW/SIZE/BRIGHTNESS가 바로 바뀌고, DISTANCE UNIT을 NM으로 바꾸면 피퍼 거리·표적 마커 거리·페이즈 진행 글자의 남은 거리가 NM으로. 다음 접속에도 남는다

- [ ] 비·폭풍: 층 아래에서 올려다봐도 뭉게구름 윤곽이 보이지 않는다. 층 위에서는 일부 구름이 층에서 솟아 있고 잘린 선이 부드럽다. 층 안(1300~1800m)을 날아도 밝은 구름 안개가 끼어들지 않는다

- [ ] 날씨가 맑음 ↔ 비로 바뀌는 5초 동안 낮은 뭉게구름이 디더링으로 사라지고 나타난다. 맑은 날씨의 뭉게구름은 전과 같다. 공중 요새·폭격기의 층 경계 효과는 그대로
- [ ] 구름을 바라보고 시점을 돌려도 화면에 고정된 점이 보이지 않는다(뭉게구름·층 모두). 구름에 아주 가까울 때의 디더 페이드는 그대로

## 7-82. 난이도 곡선
- [ ] Bake → 로그 "페이즈 가중치 기본값" → 씬 저장. ACO → Missions → Phase Weights에서 값 확인
- [ ] 5페이즈 미션: 앞은 쉬운 임무, 뒤로 갈수록 어려운 임무가 나온다. 4페이즈에 함대전, 5페이즈에 요새가 자주 나온다. 3페이즈 미션엔 요새가 안 나온다
- [ ] 1페이즈 적기가 대부분 RKY(신병)이고 5페이즈는 VET·ACE가 많다. 1페이즈 SAM·포는 느리고 빗나가며, 5페이즈는 락온이 빠르고 잘 맞는다(같은 프리팹이 다음 스폰에서 달라진다). 지상 유닛 체력: 에이스는 잘 안 죽고(×1.3), 체력 바가 스폰 직후 가득 차 있다. 재사용된 유닛도 숙련도에 맞는 체력으로 살아난다. 로그 "기준 체력(BaseHealth, 베테랑)"
- [ ] 보너스: 5페이즈를 깨면 언제나 보너스가 붙는다(풀에 슈퍼에이스가 있을 때). 1페이즈는 드물게 붙는다(디버그 패널 BONUS로 100%로 시험). 패널이 처음엔 BY PHASE, 버튼을 누르면 고정 %로 보이고 ACE·VETERAN 버튼도 효과가 있다
- [ ] 늦게 들어온 클라이언트도 같은 체감(피격 판정은 맞는 쪽이므로 값이 같아야 한다). 균형: 5페이즈가 4명에게 지나치게 어렵지 않은지, 1페이즈가 너무 쉽지 않은지. 안 맞으면 PhaseVeteranChance·PhaseAceChance·Ground*Multiplier

## 7-83. 데칼 스튜디오 개선
- [ ] 프리팹 생성 창 → 데칼 스튜디오 다시 만들기 → Bake → 씬 저장(프리팹을 직접 고친 내용·건 위치는 덮어써진다). 씬의 건 위치 확인
- [ ] 데칼을 찍으면 스프레이 소리가 난다(샘플을 빗맞히면 안 난다). 이미지를 불러오면 패널 오른쪽 아래 창에 보이고 세로·가로 이미지도 비율이 맞는다. 처음엔 NO IMAGE, 받는 동안은 이전 이미지가 남는다. 긴 실패 글자가 창과 겹치지 않는다
- [ ] 아이콘이 글자와 겹치지 않는다. 건을 집으면(데스크톱·VR) 총구가 앞을 보고 손잡이 자리가 자연스럽다(어색하면 DecalGun/Grip 위치). 놓으면 그 자리에 떠 있다. RESET GUN은 들고 있어도 받침대로 돌아간다
- [ ] 이미지 A → B → A를 번갈아 LOAD: A로 돌아오면 바로 바뀐다(LOADING에 멈추지 않는다). 빠르게 여러 개 LOAD해도 마지막 것이 먼저 받아진다. 잘못된 URL은 다시 시도 뒤 실패 글자가 나오고 LOAD로 다시 시도할 수 있다. 이미지를 17장 넘게 바꿔도 지금 고른 이미지는 안 사라진다. 다른 사람 기체의 데칼도 전처럼 받아진다

## 7-84. 랜스 포대(지상 보스)
- [ ] (먼저) 컴파일 → Bake: 로그 "NPC_Railgun", "Phase_Railgun" → 씬 저장. 프리팹을 열어 모양·텍스처·포신 방향(+Z)·장갑을 손으로 돌려 보기. 디버그 패널 LANCE BATTERY의 P1
- [ ] 페이즈 시작: 평평한 땅에 기초가 묻히지 않고 선다. 포구가 플레이어 쪽. 공대지 무장이 방공 부위를 잠근다. 진행 글자 AA n/16  BASE 3/3  FIRE m:ss
- [ ] 90초마다 포신이 들리고 빛·충전음이 커지며, 5초 전 붉은 레이저, 발사 빔과 포구 섬광, 거리만큼 늦은 발사음. 기지 내구도가 3 → 2 → 1 → 0, 0이면 6초 뒤 BASE DESTROYED 실패. 사선 안에서 맞으면 큰 피해, 밖이면 없다
- [ ] 발사 0.5초 뒤 사선 방향 지평선이 번쩍이고 주황 빛이 몇 초 남는다. 구름·안개가 잠깐 밝아지고 4초 뒤 먼 폭음. 비·안개 속에서도 보이고, 산 뒤면 능선 뒤로 번쩍인다. 너무 크거나 작으면 HorizonDistance·HorizonFlash 크기
- [ ] 소형 레일건: 로그 "소형 레일건 4문"(또는 먼저 만든 프리팹이면 "사선 레이저"). 포대 근처(6.5km)에서 얇은 붉은 레이저가 내 앞쪽을 1.5초 따라오다가, 쏘는 순간 굵어지며 고정되고 빛나는 탄이 날아와 3초 뒤 레이저 끝에서 터진다(레이저가 꺼진다). 다른 사람을 노리는 레이저도 보인다. 소리: 발사음, 폭발음. 직진하면 폭발 속으로 들어가 0.5초마다 피해, 쏜 뒤 방향을 틀면 피한다. 폭발 지역이 3.5초 남고 그 안으로 다시 들어가면 맞는다. 첫 사격에 AWACS 경고. 공대지로 부술 수 있고 진행 글자 AA n/16, 수리로 다시 살아난다. 위력·빈도가 답답하지 않은지(FireInterval, ZoneDamage)
- [ ] 방공망을 다 부수면 냉각기가 잠긴다. 부술 때마다 FIRE 시간이 15초 늘고 다음 충전도 길다. 전부 부수면 코어 단계. 40초마다 방공 일부가 살아난다
- [ ] 코어: 발사 25초 전 장갑이 열리고(좌우가 눕고 위가 트임) 재장전이 끝나면 닫힌다. 열렸을 때만 락온·피해. SCM 같은 탑어택 무장이 위에서 들어가 맞는다. 닫힐 때 날아가던 미사일은 놓친다
- [ ] 코어 격파: 연쇄 폭발 → 대폭발 → 4초 뒤 성공. 모델이 사라진다. 다음 미션에서 다시 정상으로 나온다. 늦게 들어온 클라이언트의 포신·장갑·발사 시각이 같다
- [ ] 대사: 적 뒤 AWACS. 인스펙터 표가 랜스 포대 상황 이름으로 보인다. 요새 대사도 전처럼 나온다(공통 부모로 옮겼다). 균형: 기본 시간 안에 4명이 깰 수 있는지, 공대공만 가져온 사람이 할 일이 있는지(코어 3000, 냉각기 700, BeamDamage 120). 프레임

## 7-103. 총탄이 스치는 소리

- [ ] 멀리서 다른 표적이나 다른 플레이어를 쏠 때는 나지 않는다. 내가 조종하지 않을 때도 나지 않는다
- [ ] 여러 대가 동시에 쏴도 시끄럽게 겹치지 않는다. 소리가 총탄처럼 들리고 음량이 적당하다

- [ ] 킬마크: 미션이 끝날 때(성공·실패) 쓰러뜨린 수가 최고 기록을 넘으면 늘어나고(미션 중에는 그대로, 도중에 나가면 기록 안 됨), 10개·100개에서 아이콘이 바뀐다. 아이콘 경계가 또렷하고 뒷면이 보이지 않는다

## 7-105. 자유 비행 모드
- [ ] Bake → 로그 "자유 비행 버튼" → 씬 저장. 콘솔의 NEW TERRAIN 옆에 버튼이 있고 글자가 넘치지 않는다
- [ ] 버튼 아랫줄에 바꿀 수 있는 사람의 이름이 나오고 넘치지 않는다. 한글·일본어 이름도 보인다. 인스턴스 오너가 아니면 버튼이 회색이고 눌러도 거절된다. Friends/Invite 인스턴스에서 확인, Public·Group 인스턴스 동작도 확인
- [ ] 켜면 작전 테이블과 맵의 NPC가 모두 사라지고 READY가 막힌다. 늦게 들어온 사람도 같게 보인다
- [ ] JOIN 후 LAUNCH로 갑판에 나간다. 명단 밖이어도 빈 기체 조종석을 눌러 탈 수 있다
- [ ] 활주로·갑판·먼 곳에서 내려도 기체가 그대로 있고 나도 순간이동되지 않는다(30초 넘게 기다려도)
- [ ] 내려도 강화(체력 등), 데칼, 소모품 외형이 남는다. 다시 타도 정상이고, 다른 사람이 타면 그 사람 값이 된다
- [ ] 격추되면 격납고로 돌아가고 기체는 보관 장소로 간다. LAUNCH로 다시 나갈 수 있고 사양이 다시 적용된다
- [ ] 비행 중에 끄면 화면이 어두워지며 내려서 브리핑실로 돌아가고, 기체가 바로 회수된다. 빈 기체도 바로 회수된다. 걸어서 안전지대에 있던 사람은 그대로다
- [ ] 끈 뒤 지형이 새로 만들어지고 NPC 미리 배치가 돌아오며 READY가 된다. 다른 플레이어 화면도 같다
- [ ] 바꾼 뒤 10초 동안 버튼이 회색이고 남은 초가 줄어든다. 그동안 눌러도 거절된다. 지형을 만드는 도중 다시 켜도 NPC가 나오지 않고 렉이 심하지 않다
- [ ] 끈 뒤 정상 미션이 시작되고, 내리면 사양이 평소처럼 초기화된다

## 7-106. 과반 READY 자동 시작 표시
- [ ] Bake 후 `ReadyCountdown`이 30이다. 값을 바꾸고 다시 Bake해도 그대로다
- [ ] 명단 절반 이상 READY: 시작음과 함께 콘솔 배너 맨 위에 AUTO START IN n이 크게 나오고, 상태 패널도 크게 보인다
- [ ] READY 안 한 사람에게 빨간 안내가 나오고, 명단에 있으면 어디를 봐도 머리 앞에 남은 시간이 보인다. READY하면 안내 문구가 바뀐다
- [ ] 마지막 5초에 소리가 난다. 전원 READY가 되면 기존 10초 출격 카운트다운으로 넘어간다. READY를 풀어 과반이 깨지면 표시가 사라진다

## 7-107. 작전판 순위와 패널 정리
- [ ] Bake → 로그 3종(작전판, 격납고, 관전 패널) → 씬 저장
- [ ] 작전판이 약 70% 크기다. 벽·다른 물체와 겹치지 않고 스크롤 버튼이 눌린다. 글자가 읽힌다
- [ ] 긴 실패 사유·보상 줄이 있는 디브리핑 결과가 제목 칸 안에서 줄을 바꿔 판 밖으로 나가지 않고, SCORE 제목과 겹치지 않는다
- [ ] BEST MISSION PAY: 아이콘이 보이고, 미션이 끝나면 기록이 갱신되고, 높은 순으로 나온다. 재접속해도 남고 다른 사람 기록도 보인다. 조종사 집계와 겹치지 않는다
- [ ] 격납고: 항목이 카드보다 어둡고 눌리는 곳이 구분된다. 선택·보유·장착·잠김·살 수 없음이 구분되고 글자가 잘 읽힌다
- [ ] 관전 패널: POWER 등 아이콘과 글자 사이가 떨어져 있고 글자가 버튼을 넘지 않는다

- [ ] (먼저) Tools 창 "육각 지형 자연 머티리얼" [적용] → 콘솔 로그, ACO_HexColumn 프리팹 머티리얼 = ACO_HexTerrainNatural, 셰이더 컴파일 오류 없음
- [ ] 텍스처 3장 가져오기: Detail/Macro sRGB 꺼짐·Repeat, DetailNormal = Normal map
- [ ] 해안 모래(물가 젖은 모래) → 풀/마른 풀/숲 → 흙 → 바위 → 산꼭대기 눈, 경계가 들쭉날쭉 섞이고 육각 칸 경계에서 색이 끊기지 않는다
- [ ] 절벽(수직 벽)에 지층 줄무늬, 비탈(치마)과 윗면 사이 음영 꺾임이 예전보다 덜 보인다(_SlopeFlatten 0 ↔ 1 비교)
- [ ] 저공(수백 m)에서 지면 잔결·요철이 보이고, 고공에서 같은 무늬가 바둑판처럼 반복돼 보이지 않는다
- [ ] 리롤로 지형이 바뀌어도 그대로, 성능(드로우콜 — GPU 인스턴싱) 이전과 비슷
- [ ] (나무) [다시 적용] 후 ACO_HexColumn 프리팹에 자식 Trees(LOD Group, 그림자 끔), 셰이더 ACO/HexTrees 컴파일 오류 없음
- [ ] 지면의 짙은 숲 얼룩 위에만 나무가 빽빽하고 가장자리는 성기다, 풀밭엔 가끔 외딴 나무, 해변·바위·눈엔 없다
- [ ] 낮은 곳은 활엽수(둥근), 높은 곳으로 갈수록 침엽수(뾰족), 기둥마다 배치가 같은 격자로 반복돼 보이지 않는다
- [ ] 도시·마을·비행장·등대·레이더 칸에는 나무가 없다(리롤 후에도)
- [ ] 저공 비행·지상에서 나무가 2km쯤부터 작아지며 자연스럽게 사라지고 갑자기 튀어나오지 않는다, 고공에선 지면 숲 색만
- [ ] 지형 생성(리롤) 중 끊김이 이전과 비슷, 저공에서 FPS 하락이 크지 않다(Profiler: 나무 드로우콜이 인스턴싱으로 묶인다)
